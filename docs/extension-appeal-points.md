# 크롬 확장 — 발표 어필 포인트 (예외 처리 중심)

> 2026-11-21 기준 v0.2.2. 코드 · 테스트 · PC 실제 확인으로 뒷받침되는 것만 적었다.

## 한 줄 역할
- 대시보드 배너 = **탭을 열어 둘 때** 화면 안에서 / 확장 = **탭이 없어도** 크롬만 켜져 있으면 PC 시스템 알림.
- 두 곳의 알림 규칙은 같다: 수업 10분 전 알림, 알림 시각을 놓쳤어도 시작 전이면 그 순간 남은 시간으로 1회, 이미 시작한 수업은 알리지 않음.

## 1. 알림 예외 처리
| 상황 | 처리 |
|---|---|
| 알림 시각을 놓치고 크롬을 켬 (수업 7분 전) | 바로 1회 "7분 뒤 ○○" (대시보드와 같은 규칙으로 맞춤) |
| 절전에서 깨어났는데 수업이 이미 시작됨 | 알림을 보내지 않고 다음 수업을 예약 |
| 같은 수업에 알림 이벤트가 겹침 (시작 · 설정 변경 · 주기 점검) | 작업을 한 줄로 처리하고 알린 기록을 남겨 **1회만** 알림 |
| 같은 시각에 수업이 두 개 | 수업마다 한 번씩 알림 |
| 알림 시각보다 일찍 울림 | 1분 넘게 이르면 보내지 않고 다시 예약 |
| 시계 변경 · 절전으로 예약이 어긋남 | 30분마다 다시 예약하고, 코드가 연결돼 있으면 서버에서 시간표도 다시 받음 |
| 알림 끄기 · 시점 변경 (5/10/15분) | 바뀌는 즉시 예약을 지우거나 다시 잡음 |

## 2. 네트워크 · 데이터 예외 처리
| 상황 | 처리 |
|---|---|
| 서버에 닿지 않음 (인터넷 끊김) | 저장본으로 그대로 표시하고 "오프라인 · 마지막 동기화 시각" 표시 — **PC에서 확인** |
| 서버가 5초 동안 응답 없음 | 기다림을 끝내고 "서버 응답이 없어요" 안내 |
| 없는 코드 입력 | "이 코드로 저장된 시간표가 없어요" (서버 404) |
| 코드 형식 오류 | 서버에 묻기 전에 "영문 소문자 · 숫자 8자리" 안내 |
| 연결 실패 | 받기에 성공한 경우에만 코드를 저장 → 잘못된 코드가 남지 않음 |
| 시간표 데이터가 깨짐 | 버전 · 요일 · `HH:MM` · 시작 < 종료 · 과목명을 검사해 사람이 읽을 문장으로 안내 |
| 서버 데이터에 HTML이 섞임 | 화면에는 항상 글자로만 넣음(`textContent`) → 스크립트 삽입 방지 |

## 3. 시간 경계
- 오늘 상태 6가지를 구분한다: 등록된 수업 없음 · 오늘 수업 없음 · 첫 수업 전 · 수업 중 · 공강 · 오늘 끝.
- 오늘 수업이 없거나 끝났으면 "내일 / ○요일 / 다음 주 ○요일 첫 수업"을 안내한다.
- 시작 정각은 "수업 중", 종료 정각은 "끝남"으로 본다.
- 금요일 → 다음 주 월요일(주 넘김)과 11/30 → 12/1(월 넘김)도 계산한다.

## 4. 개인정보 · 보안
- 로그인 · 계정 · 비밀번호 없이 8자리 코드만 쓴다. 기상 시각 · 버스 · 주소는 다루지 않는다.
- 외부 CDN · 원격 코드가 없다 (크롬 MV3 규칙). 접속하는 서버는 하나뿐이다(`host_permissions`).

## 5. 검증 근거 (숫자로 말하기)
- 자동 테스트 **77개 PASS** — 늦게 켬 · 중복 알림 · 경계 시각 · 주/월 넘김 포함
- 배포 전 점검(`/ext-check`) **7항목 통과** — 테스트 · JSON · 문법 · 파일 참조 · 외부 주소 · 서버 주소 일치
- 알림 흐름 모의 실행 **8항목 통과** — 가짜 크롬 API로 늦게 켬(바로 1회) · 재시작해도 다시 안 알림 · 이벤트 겹침 · 시작 후 켬 · 알림 끔 확인
- PC 실제 확인: 알림 수신 · 대시보드 동기화 코드 연결 · 인터넷 끊김 시 저장본 표시

## 6. 한계 (먼저 말하면 오히려 플러스)
- 크롬이 실행 중이어야 하고, 노트북 절전 · Windows 방해 금지 모드에서는 알림이 오지 않는다 → **폰 알람을 대신하지 않는다** (기상 알림은 서버 → 폰 담당).
- 대시보드 배너와 확장 알림을 둘 다 켜 두면 같은 수업에 각각 한 번씩 올 수 있다 (기록이 서로 따로).

## 예상 질문
- **크롬을 늦게 켜면 알림을 놓치나요?** → 수업 시작 전이면 그 순간 남은 시간으로 바로 알려 줍니다.
- **인터넷이 끊기면요?** → 마지막으로 받은 시간표로 계속 보이고 알림도 그대로 옵니다.
- **알림이 두 번 오지 않나요?** → 수업마다 알린 기록을 남기고 작업을 한 줄로 처리해서, 이벤트가 겹쳐도 한 번만 옵니다(테스트로 확인).
