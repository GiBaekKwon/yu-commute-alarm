# 영남대 통학 기상 알리미 — 프로젝트 기획서

> "내일 몇 시에 일어나야 해?"를 대신 계산해 주는 통학생용 웹 서비스
> 작성일: 2026. 11. 15. / 과목: 영남대학교 Agentic AI 강의 과정 팀 프로젝트 (Day 7~8)

## 1. 결론 요약
- 시간표와 통학 경로를 한 번 등록하면, 수업 시작 시각에서 거꾸로 계산해 **요일별 기상 시각 · 탈 버스 · 출발까지 남은 시간**을 보여 주는 웹사이트를 만든다.
- 네이버클라우드 서버의 Nginx로 배포하며, 화면은 순수 HTML · CSS · JS로 만든다.
- 웹은 **알림까지만** 담당하고, 실제 기상 알람은 사용자가 폰에서 맞춘다. 서비스의 역할은 "알람을 몇 시에 맞춰야 하는지 정해 주는 것"이다.
- 크롬 확장 프로그램은 PC용 보조 기능으로, 시간이 남을 때만 만든다.

## 2. 문제 정의
| 구분 | 내용 |
|---|---|
| 불편 | 1교시가 있는 날마다 몇 시에 일어나 몇 시 버스를 타야 하는지 지도 앱으로 매번 검색한다 |
| 심화 요인 | 경산 · 대구 버스는 배차 간격이 길어 한 대만 놓쳐도 지각한다 |
| 대상 | 영남대(경산) 통학생 |
| 발표 첫 문장 | "버스 한 대 놓쳐서 1교시 지각한 적 있죠?" |

## 3. 유사 서비스와 차별점
(조사일 2026. 11. 15., 별도 조사 문서 기준. 링크는 발표 전 재확인 필요)

| 구분 | 대표 서비스 | 되는 것 | 안 되는 것 |
|---|---|---|---|
| 지도 앱 | 네이버지도 · 카카오맵 · 구글 지도 | 도착 시간 기준 길찾기 | 매번 직접 검색, 기상 시각 · 요일 반복 없음 |
| 시간표 앱 | 에브리타임 · 타임스프레드 | 시간표 관리, 수업 · 기상 알람 | 통학 경로 계산 없음 |
| 해외 알람 앱 | CommuteWize · EarlyOtter 등 | 일정 기준 기상 시각 계산 | 자동차 · 교통량 기준, 국내 버스 · 학생 시간표 미지원 |
| 개인 프로젝트 | Wuasta (GitHub) | 도착 시각 → 기상 시각 역산 | 자동차 기준, 시간표 반복 없음 |

**차별점**
1. 시간표 + 준비 시간 + 버스 + 도보를 묶어 **요일별 기상 시각**까지 자동 계산
2. 영남대 · 경산 특화: 배차 간격이 긴 버스, 정류장 → 강의동 도보 시간 반영
3. 놓쳤을 때 다음 버스와 지각 예상 시간까지 안내

## 4. 기능 범위
### 4-1. 필수 기능 (3개)
| 기능 | 화면 구성 |
|---|---|
| 오늘 화면 | 오늘 남은 수업 목록, 출발까지 · 다음 수업까지 카운트다운, 탈 버스 |
| 주간 화면 | 미니 시간표, 요일별 기상 시각 (예: 월 8:10 · 화 7:20 · 수 공강) |
| 등록 화면 | 시간표 입력, 통학 경로 입력 (준비 시간 · 도보 · 버스 번호와 시각) |

오늘 화면 예시:
```
🚌 출발까지 00:12:35   (8:05 ○○번 버스)
📚 자료구조까지 00:59:10 (공학관 302호)

오늘 남은 수업
• 09:00 자료구조
• 13:00 운영체제
```

### 4-2. 있으면 좋은 기능
| 기능 | 방법 |
|---|---|
| 전날 밤 브리핑 | 서버가 매일 밤 Telegram 또는 ntfy로 "내일 7:20 기상, 8:05 ○○번" 발송 |
| 알람 설정 돕기 | 주간 알람 목록 표시, 캘린더 파일(.ics) 내려받기 |
| 놓쳤을 때 다음 버스 | 한 대 놓치면 몇 분 늦는지 표시 |
| 크롬 확장 프로그램 | PC 크롬 팝업에서 미니 시간표 · 오늘 남은 수업 · 다음 수업 카운트다운 표시 (노트북 사용 중 = 이미 이동 · 작업 중이므로 기상 시각 · 버스는 제외) |
| 실시간 버스 도착 | 공공 API 연동 |

### 4-3. 하지 않을 것
| 항목 | 이유 |
|---|---|
| 에브리타임 자동 연동 | 이용약관 문제 가능성, 기본은 직접 입력 |
| 집 주소 저장 | 개인정보 부담, 걸리는 시간(분)만 저장 |
| 길찾기 경로 자동 계산 | 대중교통 경로 API가 필요해 개발 범위 초과 |
| 웹에서 알람 직접 울리기 | 브라우저가 닫히거나 화면이 꺼지면 불가 |

## 5. 기상 시각 계산 규칙
```
기상 시각 = 탈 버스 출발 시각 − 집→정류장 도보 − 준비 시간
탈 버스   = (첫 수업 시작 − 하차 후 강의실 도보 − 버스 소요 시간) 이전에 출발하는 가장 늦은 버스
```
| 입력값 | 예시 |
|---|---|
| 첫 수업 시작 | 09:00 |
| 하차 후 강의실 도보 | 8분 |
| 버스 소요 시간 | 40분 |
| 집 → 정류장 도보 | 5분 |
| 준비 시간 | 40분 |
| 결과 | 8:05 버스 → 7:20 기상 |

## 6. 시스템 구조
```
[사용자 PC · 폰 브라우저]
        │  http://<공인 IP>/wakeup/
        ▼
[네이버클라우드 서버 · Nginx]
  ├─ 정적 웹 (HTML · CSS · JS)       ← 필수
  ├─ 시간표 데이터 (JSON / Flask API) ← 서버 저장 시
  └─ 전날 밤 알림 (cron · systemd)    ← 있으면 좋은 기능
        │
        ▼
[Telegram · ntfy 앱] → 사용자가 폰 알람 설정
```

| 구성 | 단계 | 비고 |
|---|---|---|
| 정적 웹 | 1단계 | `/var/www/html/wakeup/`에 복사하면 배포 완료 |
| 서버 저장 | 2단계 | Day 4 메모 앱 구조(Flask + JSON) 재사용, PC · 폰 같은 시간표 |
| 전날 밤 알림 | 3단계 | 서버 → Telegram · ntfy, 우리 서버에 HTTPS 없어도 가능 |
| 확장 프로그램 | 선택 | 서버는 zip과 설치 안내만 제공, 실행은 사용자 크롬 |

## 11. 시연 시나리오 (약 3분)
1. 불편: "버스 한 대 놓쳐서 1교시 지각한 적 있죠?"
2. 등록: 청중 한 명의 첫 수업 시간과 통학 시간을 즉석 입력
3. 결과: 주간 화면에 요일별 기상 시각, 오늘 화면에 카운트다운 표시
4. 알림: 발송 시각을 1분 뒤로 설정해 폰으로 브리핑 도착 장면
5. 마무리: 주간 통학 계획표 PDF를 스킬로 생성해 보여 주기
