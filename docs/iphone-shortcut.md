# 아이폰 단축어 "통학알람" — 요일별 기상 알람 자동 등록

> 2026-11-21 실제 아이폰에서 확인: 요일 반복 알람 생성 · "통학" 알람 삭제 후 재생성(중복 없음) · 빈 요일 건너뜀.

## 흐름
```
대시보드 통학 계획 (요일별 기상 시각, 내 시간표 모드에서만)
  → [아이폰 알람 등록] 버튼 (PC는 QR)
  → shortcuts://run-shortcut?name=통학알람&input=text&text={"1":"07:20","3":"08:10"}
  → 단축어: "통학" 레이블 알람 모두 삭제 → 요일별 반복 알람 생성
```
- 처음 한 번은 단축어 설치가 필요하다 (iCloud 링크 → "단축어 추가"). 링크는 `site/js/dashboard.js`의 `SHORTCUT_INSTALL_URL`.
- 시간표나 통학 시간을 바꾸면 버튼을 다시 누른다 (예전 알람은 단축어가 지운다).

## 데이터 형식 (`site/js/commute.js` `shortcutAlarms` · `shortcutUrl`)
- JSON 사전 `{ "요일": "HH:MM" }`, 요일은 알람이 울릴 요일 `0=일 … 6=토`. 수업 없는 요일은 키가 없다.
- 기상이 자정 전으로 넘어가면(예: 화 01:00 수업 → 월 23:33) **전날 요일**로 옮긴다.
- 옮긴 알람이 그 요일 자기 알람과 겹치면(같은 요일 알람이 두 개 필요) 넣지 않고 화면에서 "직접 맞춰 주세요"로 안내한다 (단축어는 요일마다 알람 하나).
- 예시 체험 모드에서는 버튼을 숨긴다 (예시 시각으로 진짜 통학 알람이 지워지지 않게).
- 테스트: `site/test.html` 통학 50 ~ 53, `tests/dashboard.test.js` "아이폰 알람" 2건.

## 단축어 구성 (다시 만들 때)
1. 이름 `통학알람` (띄어쓰기 없이 — 실행 주소의 `name`과 같아야 함)
2. 맨 위 입력: 텍스트 받기, **입력이 없는 경우: 중단** (데이터 없이 실행돼 알람만 지워지는 것 방지)
3. `단축어 입력에서 사전 가져오기`
4. `다음 조건에 맞는 알람 찾기` — 레이블 · 다음을 포함 · `통학`, **제한 끔** → `알람 삭제`
5. 요일마다 (키 0 ~ 6):
   ```
   사전에서 [키]에 대한 값 가져오기
   만약 [사전 값] 값을 가지고 있음
       [사전 값]에 '통학.요일' 알람 생성 (반복: 그 요일)
   만약 종료
   ```
   블록을 복제했으면 각 "사전 값"이 바로 위 "값 가져오기"를 가리키는지 확인한다.
