# ODsay 대중교통 길찾기 API 테스트 기록

> 테스트일: 2026. 11. 21. / 테스트 위치: 팀원 네이버클라우드 서버 (`~/wakeup`)
> API 키 값은 이 문서에 적지 않는다.

## 1. 결론
- ODsay `searchPubTransPathT`로 **출발 · 도착 좌표만 넣으면 경로, 총 소요 시간, 도보 시간, 배차 간격**을 받을 수 있다.
- 테스트(반월당 → 영남대 앞)에서 **지하철 2호선 경로가 총 33분**으로 가장 빨랐고, CSV로 계산한 반월당 → 영남대 26.8분과 일치한다.
- **도보 시간 문제 해결**: 응답의 도보 구간(`trafficType: 3`)에 걷는 거리와 시간이 들어 있다.

## 2. 설정
| 항목 | 내용 |
|---|---|
| 가입 | ODsay LAB 회원가입 → 애플리케이션 등록 |
| 플랫폼 | Server, 서버 공인 IP 등록 (`http://` 없이 숫자만), 반영까지 최대 1분 |
| 키 보관 | 서버 `.env`의 `ODSAY_KEY`에만, 코드 · GitHub · 단톡방 금지 |

## 3. 테스트 명령
```bash
read -s ODSAY_KEY
curl -G "https://api.odsay.com/v1/api/searchPubTransPathT" \
  --data-urlencode "apiKey=${ODSAY_KEY}" \
  --data-urlencode "SX=128.59562" \
  --data-urlencode "SY=35.86526" \
  --data-urlencode "EX=128.7542" \
  --data-urlencode "EY=35.8369"
```
- `SX · EX` = 경도(128.xxx), `SY · EY` = 위도(35.xxx)
- 출발: 2호선반월당역1 정류장 좌표 (TAGO `cityCode=22`, `nodeNm=반월당`으로 조회)
- 도착: 영남대 앞 정류장 좌표 (TAGO `cityCode=37100`)

## 5. 응답 구조
| 위치 | 필드 | 뜻 |
|---|---|---|
| `result.path[]` | `pathType` | 1 지하철, 2 버스, 3 버스+지하철 |
| `path[].info` | `totalTime` | 총 소요 시간 (분) |
| | `totalWalk` | 총 도보 거리 (m) |
| | `payment` | 요금 (원) |
| | `busTransitCount` · `subwayTransitCount` | 버스 · 지하철 이용 횟수 |
| | `totalIntervalTime` | 배차 간격 합 (분, 추정) |
| `path[].subPath[]` | `trafficType` | 1 지하철, 2 버스, **3 도보** |
| | `sectionTime` | 그 구간 소요 시간 (분) |
| | `distance` | 그 구간 거리 (m) |
| | `intervalTime` | 그 노선 배차 간격 (분) |
| | `lane[].name` · `lane[].busNo` | 지하철 노선 이름 · 버스 번호 |
| | `startName` · `endName` | 승차 · 하차 역 / 정류장 |
| | `startExitNo` · `endExitNo` | 지하철 출구 번호 |
| | `startLocalStationID` | TAGO 정류장 ID와 같은 값 (예: `DGB7001012300`) → 실시간 도착 조회에 연결 가능 |

주의: `info.totalWalkTime`은 `-1`로 와서 쓸 수 없다. 도보 시간은 `trafficType: 3` 구간의 `sectionTime`을 더해서 구한다.

## 6. 기획 반영
| 기능 | 데이터 |
|---|---|
| 등록 화면 | 출발지(집 근처 정류장 · 역)와 강의동 선택 → ODsay로 경로 후보 표시 → 사용자가 1개 선택 → 저장 |
| 소요 시간 · 도보 시간 | ODsay 결과의 `totalTime`, 도보 구간 `sectionTime` |
| 정확한 탈 시각 | 지하철: 대구교통공사 시간표 / 버스: 배차 간격 또는 TAGO 실시간 |
| 오늘 아침 | 저장된 정류장 ID로 TAGO 실시간 도착 조회 |

- 경로는 **등록할 때 한 번만** 조회해 저장한다 (매일 호출하지 않아 호출량 절약).
- 정확한 집 좌표 대신 **집 근처 정류장 · 역 좌표**를 출발지로 써서 개인정보를 줄인다.

## 7. 한계
| 항목 | 내용 |
|---|---|
| 출발 시각 | 요청에 시각을 넣지 않아 "평소 기준" 소요 시간이다 (시간 지정 기능 여부 확인 필요) |
| 캠퍼스 안 도보 | 도착이 정류장 · 역이라 강의동까지 도보는 별도 (팀 측정 표) |
| 배차 대기 | 총 시간에 기다리는 시간이 포함되는지 확인 필요 |

## 8. 확인 필요
- ODsay 무료 하루 호출 한도와 학생 프로젝트 사용 조건
- 도착지를 강의동 좌표로 넣으면 캠퍼스 안 도보까지 계산되는지
- 출발 시각을 지정하는 요청 변수가 있는지
- `pathType`, `totalIntervalTime`의 정확한 정의 (ODsay 문서 기준)
