# 팀 프로젝트 점수 자가 점검 — 통학 기상 알리미

> 점검일: 2026. 11. 21. / 기준: 강의 슬라이드 "팀 프로젝트 평가 기준 — 채점 기준"
> 현재 단계: 기획 · 데이터 검증 완료, 개발 진행 중(결과 미확인), 배포 · 시연 전

## 1. 결론
- **기획으로 받을 수 있는 1번(문제 정의)은 이미 탁월 수준**이고, 2번(Agentic AI)은 **SKILL.md 하나와 오류 해결 기록**만 더하면 탁월로 올라갈 수 있다.
- 3 · 4 · 5번(웹 구현, 배포, 시연)은 아직 결과물이 없어 **산정할 수 없다(확인 필요)**. 점수의 55%가 여기 달려 있으므로 Day 7~8은 **완성 · 배포 · 리허설**에 집중해야 한다.

## 3. 2번 Agentic AI — 탁월 조건 맞추기
채점 기준: "CLAUDE.md · SKILL.md 로 제어 및 오류를 AI와 함께 스스로 해결"

| 조건 | 현재 | 할 일 |
|---|---|---|
| CLAUDE.md로 제어 | ○ 작성 완료 | 발표에서 규칙이 실제로 지켜진 장면(예: 개인정보 저장 거절) 보여 주기 |
| SKILL.md로 제어 | ✗ 없음 | 나만의 스킬 1개 만들기 (아래 후보) |
| 오류를 AI와 함께 해결 | △ 기록 없음 | 겪은 오류를 표로 정리해 발표 자료에 넣기 |

SKILL.md 후보:
| 스킬 | 하는 일 | 장점 |
|---|---|---|
| `weekly-commute-pdf` | 시간표 · 경로 → 주간 통학 계획표 PDF | 시연에서 결과물이 눈에 보임 |
| `timetable-to-json` | 대구교통공사 CSV → 앱용 JSON 변환 규칙 | 데이터 갱신 때 재사용, 실제로 필요한 작업 |
| `route-check` | ODsay · TAGO 응답을 검증하는 점검표 | 오류 해결 과정과 연결 |

지금까지 AI와 함께 해결한 오류 (발표 자료 소재):
| 오류 | 원인 | 해결 |
|---|---|---|
| Hermes 설치 실패 | 서버 디스크 100% | 커널 · VS Code 캐시 정리로 3.6G 확보 |
| 기획서를 찾지 못함 | 서버에 파일 미업로드 | heredoc 명령으로 파일 생성 |
| PDF 404 | 웹 폴더에 미배포 | 배포 경로 확인 후 복사 |
| `SERVICE_KEY_IS_NOT_REGISTERED` | 두 API 키가 서로 바뀜 | 키 길이로 구분해 다시 입력 |
| ODsay IP 등록 실패 | `http://`를 붙여 입력 | 숫자만 입력 |
| scp 실패 | 괄호 · 띄어쓰기, 포트 2222 | 따옴표, `-P 2222` |
| 지하철 방향 혼동 | 2호선 상선이 영남대 출발 방향 | 하선 CSV로 등교 방향 확인 |
