# 대구 도시철도 시각표 분석 (v2)

> 분석일: 2026. 11. 21. / 출처: 대구교통공사 열차시각표 CSV(공공데이터포털), 대구교통공사 역별 시간 Open API
> 분석 파일: 1 · 2 · 3호선 상선 · 하선 CSV (기준일 2024-10-07 ~ 2024-10-10)

## 1. 결론
- **2호선 하선 = 문양 → 영남대 방향(등교)**, 2호선 상선 = 영남대 → 문양 방향(귀가)이다.
- 하선 CSV로 **2호선 각 역에서 영남대까지 걸리는 시간**을 계산했다 (7장). 예: 반월당 26.8분, 범어 21.1분.
- 추천 방식: **출발 시각은 대구교통공사 Open API(최신)**, **영남대까지 소요 시간은 CSV로 계산한 고정값**을 쓴다.

## 2. 데이터 출처 비교

|---|---|---|
| 기준 | 2024년 10월 | 최신일 가능성 높음 (확인 필요) |
| 단위 | 열차별 (모든 역의 도착 · 출발) | 역별 (그 역 출발 시각 목록) |
| 영남대 도착 시각 | 같은 열차로 바로 확인 | 없음 → 소요 시간을 더해야 함 |
| 중간 종착 열차 | 빈칸 | 시각 뒤 괄호 (예: `6:48:00(안심)`) |
| 시각 형식 | `07:31:20` | `7:31:00` (앞자리 0 없음) |
| 요일 | 평일 · 토요일 · 휴일 | 요청 방법 확인 필요 |

## 3. CSV 파일 구조
| 항목 | 내용 |
|---|---|
| 인코딩 | CP949 (UTF-8 변환 필요) |
| 모양 | 한 행 = 역 하나의 도착 또는 출발, 한 열 = 열차 하나 |
| 열 | `요일별, 역명, 구분, 열차번호1, 열차번호2, …` |
| 요일별 값 | `평일(상/하)`, `토요일(상/하)`, `휴일(상/하)` |
| 구분 값 | `도착` 또는 `출발` |
| 시각 형식 | `HH:MM:SS`, 자정은 `00:00:00` |
| 빈칸 | 그 열차가 해당 역에 서지 않음 |

## 8. 계산 방법
```
목표 도착 = 수업 시작 − (영남대역 → 강의실 도보)
탈 열차   = 출발역 출발 시각 + 소요 시간(7장) ≤ 목표 도착 인 열차 중 가장 늦은 것
           (괄호에 다른 종착역이 있는 열차는 제외)
기상 시각 = 탈 열차 출발 − (집 → 역 도보) − 준비 시간
```

## 10. 개발 팀원 요청 예시
```
@docs/subway-timetable-v2.md 를 읽고, docs/data/ 의 대구교통공사 2호선 하선 CSV(CP949)를 9장 형식의 JSON으로 바꾸는 변환 스크립트를 계획해줘. 원본 CSV는 수정하지 말고, 결과는 site/data/subway/ 에 요일별로 만들어줘. 하선 파일의 '휴일(상)' 표기는 '휴일(하)'로 처리하고, 영남대까지 가지 않는 열차는 제외해줘. 먼저 Plan 모드로 계획만 보여줘.
```
