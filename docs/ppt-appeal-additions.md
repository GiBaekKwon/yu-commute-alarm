### 2-2. 스킬이 부르는 배포 스크립트 `deploy.sh` — 팀 5명이 한 서버를 쓰는 문제 해결
| 장치 | 막는 사고 |
|---|---|
| 잠금(`flock`) | 두 사람이 동시에 배포 → 뒤 사람은 바로 멈춤 |
| 배포본 지문(sha256) | 누가 손으로 복사해 배포본이 바뀌었으면 멈춤 (덮어쓰기 사고 방지) |
| `?v=` 검사 | JS · CSS를 바꿨는데 버전을 안 올리면 멈춤 (11/21 캐시 사고 재발 방지) |
| 전체 테스트 | 하나라도 실패하면 배포 안 함 |
| 테스트 중 변경 감지 | 테스트하는 동안 누가 `site/`를 고치면 멈춤 → **테스트한 그대로만** 복사 |
| 백업 · 기록 | 매번 날짜 백업 + `deploy.log`(시각 · 사람 · 버전 · 파일 수 · HTTP 상태) |

### 3-2. 근거 표 (발표자 메모 · Q&A용)

**① 에타 가져오기** (`plan.md` A-2, 테스트 44개)
| 상황 | 처리 |
|---|---|
| 링크 형식 틀림 | `invalid_url` — 올바른 링크 모양 안내 |
| 없는 시간표 | `not_found` |
| 비공개 시간표 | `private` — "공개 범위를 '전체 공개'로" |
| 빈 학기 · 수업 0개 | `empty` |
| 에타 무응답(8초) · 형식 변경 | `upstream` — 잠시 뒤 다시 |
| 요청 과다 | `rate_limited` (IP당 1분 10회) |
| 시간 없는 온라인 과목 | 제외하고 "N개 제외" 표시 |
| 예전 JS가 브라우저에 남음 | "새로고침(Ctrl+F5)" 안내 (캐시 사고 대비) |

**② 수업 10분 전 알림** (`plan.md` A-3)
- 정확히 10분 0초 전 → 표시 / 10분 1초 전 → 아직 / 시작 시각(0초) → 표시 안 함
- 7분 전에 열면 "7분 남음"으로 바로 표시, 이미 시작한 수업은 건너뜀
- 같은 수업은 당일 1번 (새로고침 · 재접속해도 안 뜸), 날짜가 바뀌면 초기화, 체험 모드는 기록을 따로

**③ 크롬 확장 알림** (`docs/extension-appeal-points.md`, 테스트 77개 + 모의 실행 8항목)
- 크롬을 늦게 켬(수업 7분 전) → 바로 1회 "7분 뒤"
- 절전에서 깼는데 수업 시작됨 → 알리지 않고 다음 수업 예약
- 이벤트 겹침 → 작업을 한 줄로 처리, **1회만**
- 같은 시각 수업 2개 → 각각 1회 / 너무 일찍 울림 → 다시 예약 / 30분마다 재예약
- 서버 5초 무응답 → "서버 응답이 없어요" / 오프라인 → 저장본 + "마지막 동기화 시각" (PC 실제 확인)
- 서버 데이터에 HTML이 섞여도 글자로만 표시 → 스크립트 삽입 방지

**④ 통학 · 아이폰 알람** (`plan.md` A-1-2, `docs/iphone-shortcut.md`)
| 상황 | 처리 |
|---|---|
| 길찾기 요청 과다 · 서버 장애(429 · 5xx) | 대구 2호선 시각표로 자동 대체 |
| 역 이름을 못 찾음 | 안내 + 이동 시간 직접 입력 |

**⑤ 서버 입력 방어** (`server/app.py`, 저장 API 테스트 44개)

### 4-2. "오류 전무"라는 표현에 대해 — ⚠️ 주의
- **"오류 전무" · "예외 처리 완벽"은 쓰지 않는 것을 권장.** 평가자가 "그럼 지금 서버를 끄면요?" "공휴일은요?"라고 물으면 바로 반박된다. 14장에서 우리가 직접 한계(실시간 지연 · 공휴일 미반영)를 말하므로 앞뒤가 맞지 않게 된다.
- 대신 **검증 가능한 표현**:
  - `자동 테스트 560개 — 실패 0건`
  - `배포 5회 모두 테스트 통과 후에만 반영`
  - `알려진 실패 상황 N가지를 모두 안내 문구로 처리`
  - `실패해도 멈추지 않는다 — 대체 경로가 있다`
- 참고: 테스트는 대부분 0 FAIL로 안정적이지만, 17시 동기화 테스트에서 일시 실패 2건이 있었다가 재실행 시 통과한 기록이 있다. "한 번도 실패한 적 없다"고 말하지 말 것.
