## 1. 🔴 실제 구현과 달라서 꼭 고칠 부분

### 1-1. 통학 계산 방식이 "버스 시간표"로 설명됨 (3 · 4 · 8 · 13 · 14장)

**PPT 내용**: 노선별 평일·토·일 버스 시간표로 탈 버스 계산, 예시 "월·수 09:00 수업 → 08:05 버스 → 07:20 기상"

**실제 구현 (11/21 오후 변경, `plan.md` A-1-2)**
- 입력 4개: **출발지 · 도착지 · 준비 시간 · 여유 시간**
- 이동 시간 정하는 순서: **ODsay 길찾기 API** → (장애 시) 대구 2호선 시각표(`site/data/subway/line2.json`) → 직접 입력
- 계산: `출발 = 첫 수업 − 여유 − 이동`, `기상 = 출발 − 준비`
- 저장은 `commute = { prepMin, travelMin, bufferMin }` 분 세 개만 (출발지 · 도착지 이름은 저장 안 함)
- 버스 노선 방식은 설정 화면에서 **예전 데이터 호환용**으로만 남아 있음
- 시연 화면(체험 모드) 예시: **반월당 → 영남대 2호선, 준비 40분 · 여유 10분** → "08:05 버스" 예시는 화면에 나오지 않음

**바꿀 문구**
| 장 | 현재 | 수정 |

| 3장 "해외 알람 앱" 행 | 노선별 평일·토·일 버스 시간표로 탈 버스 계산 | 길찾기 API로 대구·경산 대중교통 이동 시간 자동 계산 |
