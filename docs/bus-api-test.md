# 버스 실시간 API 연동 테스트 기록

> 테스트일: 2026. 11. 21. / 테스트 위치: 팀원 네이버클라우드 서버 (`~/wakeup`)
> API 키 값은 이 문서에 적지 않는다.

## 1. 결론
- 국토교통부 TAGO 버스 API(공공데이터포털)로 **경산시 정류장 검색과 실시간 도착 정보 조회에 성공**했다.
- 실시간 API는 "지금 오고 있는 버스"만 알려 준다. 그래서 **내일 기상 시각 계산은 시간표 JSON**, **오늘 아침 도착 확인은 실시간 API**로 나눈다.

## 2. 사용한 API
| API | 공공데이터포털 번호 | 용도 | 상태 |
|---|---|---|---|
| 국토교통부(TAGO) 버스정류소정보 | 15098534 | 도시 코드 · 정류장 ID 찾기 | 테스트 성공 |
| 국토교통부(TAGO) 버스도착정보 | 15098530 | 정류장별 도착 예정 버스 | 테스트 성공 |
| 국토교통부(TAGO) 버스노선정보 | 15098529 | 노선 정보 (첫차 · 막차 · 배차) | 미신청 · 확인 필요 |

- 인증키는 공공데이터포털 개인 인증키 1개로, 활용신청이 승인된 API에 공통으로 쓴다.
- 요청 주소: `http://apis.data.go.kr/1613000/...` (아래 명령 참고)

## 4. 테스트 명령
서버 터미널에서 실행한다. 키는 화면과 명령 기록에 남지 않게 `read -s`로 넣는다.

```bash
# 0) 키 입력 (붙여넣고 Enter, 화면에 안 보이는 것이 정상)
read -s BUS_KEY

# 1) 도시 코드 목록
curl "http://apis.data.go.kr/1613000/BusSttnInfoInqireService/getCtyCodeList?serviceKey=${BUS_KEY}&_type=json"

# 2) 정류장 이름으로 정류장 ID 찾기
curl -G "http://apis.data.go.kr/1613000/BusSttnInfoInqireService/getSttnNoList" \
  --data-urlencode "serviceKey=${BUS_KEY}" \
  --data-urlencode "cityCode=37100" \
  --data-urlencode "nodeNm=영남대" \
  --data-urlencode "_type=json"

# 3) 정류장별 도착 예정 버스
curl -G "http://apis.data.go.kr/1613000/ArvlInfoInqireService/getSttnAcctoArvlPrearngeInfoList" \
  --data-urlencode "serviceKey=${BUS_KEY}" \
  --data-urlencode "cityCode=37100" \
  --data-urlencode "nodeId=GYB360005700" \
  --data-urlencode "_type=json"
```

## 5. 응답 필드
| 필드 | 뜻 | 예시 |
|---|---|---|
| routeno | 버스 번호 | 809 |
| routeid | 노선 ID | GYB360084253 |
| arrtime | 도착까지 남은 시간 (초로 보임, 확인 필요) | 166 → 약 3분 |
| arrprevstationcnt | 남은 정류장 수 | 2 |
| routetp | 노선 종류 | 일반버스 |
| vehicletp | 차량 종류 | 일반차량 · 저상버스 |
| nodeid · nodenm | 정류장 ID · 이름 | GYB360005700 · 영남대 앞 |

응답 예시 (일부):
```json
{"arrprevstationcnt":2,"arrtime":166,"nodeid":"GYB360005700","nodenm":"영남대 앞","routeid":"GYB360084253","routeno":809,"routetp":"일반버스","vehicletp":"일반차량"}
```

## 6. 개발 시 주의
| 항목 | 내용 |
|---|---|
| 키 보관 | 대표 서버 `/root/wakeup/.env`의 `BUS_KEY`에만 저장, `.gitignore`에 `.env` 추가 |
| 키 노출 금지 | 브라우저 코드 · CLAUDE.md · GitHub · 단톡방에 키를 넣지 않는다 |
| 호출 구조 | 브라우저 → 우리 서버 `/api/arrivals` → 서버가 TAGO 조회 → 결과만 전달 |
| 호출 한도 | 같은 정류장 결과는 1분 정도 저장해 재사용 (개발 계정 하루 한도 있음) |
| 개수 제한 | 기본 10개씩 응답, 버스가 많은 정류장은 `numOfRows`를 늘린다 |
| 빈 결과 | `items`가 비면 "다가오는 버스 없음" 표시 (밤 · 주말에 흔함) |
| 실패 대비 | API 실패 시 시간표 JSON 기준 결과로 대체 |
| 지역 | 대구 쪽 정류장은 `cityCode=22`로 조회 |

## 7. 기획 반영
| 기능 | 데이터 |

| 요일별 기상 시각 · 내일 브리핑 | 시간표 JSON (팀이 정리) |

## 8. 확인 필요
- 버스노선정보 API로 노선별 첫차 · 막차 · 배차 간격을 받을 수 있는지
- `arrtime`의 단위 (포털 문서 기준 확인)
- 대표 서버에서 누구의 인증키를 쓸지, 하루 호출 한도
- 통학생들의 집 근처 정류장 ID (같은 방법으로 검색)
