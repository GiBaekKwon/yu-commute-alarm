    확장 프로그램 설치 (PC 크롬, 처음 한 번)

    통학 알리미 확장 받기 (.zip)
    1. 받은 zip의 압축을 풀어요 → wakeup-ext 폴더가 생겨요.
    2. 주소창에 chrome://extensions 를 입력하고 오른쪽 위 개발자 모드를 켜요.
    3. 압축해제된 확장 프로그램을 로드합니다를 누르고 wakeup-ext 폴더를 골라요.
    4. 툴바의 퍼즐 모양 아이콘에서 통학 알리미를 고정하면 바로 눌러 쓸 수 있어요.

    설치한 폴더는 지우지 마세요. 지우면 확장도 동작하지 않아요.

    바로 써 보기 (예시 체험)

    1. 위 방법으로 설치한 뒤 툴바의 통학 알리미 아이콘을 눌러요.
    2. 코드 입력 화면 아래 예시 데이터로 보기를 누르면 코드 없이 카운트다운 · 오늘 남은 수업 · 수업 전 PC 알림을 써 볼 수 있어요.

    내 시간표를 연결하려면 에타 시간표를 저장한 뒤 이 카드에서 동기화 코드를 만들어요.

    PC 크롬 확장 프로그램 통학 알리미에 이 시간표를 연결해요. 동기화 코드를 만들면 시간표가 서버에도 저장되고, 확장은 그 코드로 시간표를 불러와요.

    동기화 코드

    1. 크롬 툴바에서 통학 알리미 확장 아이콘을 눌러요.
    2. 위 코드를 붙여 넣고 연결을 눌러요.

    코드를 아는 사람은 이 시간표를 볼 수 있으니 다른 사람에게 알려 주지 마세요. 연결 해제는 설정에서 할 수 있어요.
